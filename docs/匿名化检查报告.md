# 匿名化检查报告

> 检查对象：本仓库全部可公开内容（源码、构建产物、页面元信息、资源文件、部署与二维码方案）。
> 检查原则：不仅“页面上看不到单位名称”，还要求**评审可接触到的公开链接与部署资源**不泄露身份。

## 二、可复跑的检查命令

```bash
# 1) 身份关键词扫描（源码 + 入口页 + 静态资源）
grep -rnE "大学|学院|校徽|院徽|教师姓名|参赛|一等奖|二等奖|科技进步|一流本科|@[a-z0-9]+\.(com|cn|edu)|1[3-9][0-9]{9}" \
  src index.html public || echo "无匹配"

# 2) 外部链接清单
grep -rhoE "https?://[^\"')< ]+" src index.html | sort -u

# 3) 位图检查（应只有 favicon.svg 与 public/qr 下的二维码）
find public src -type f \( -iname "*.png" -o -iname "*.jpg" -o -iname "*.jpeg" -o -iname "*.webp" -o -iname "*.gif" \) -print

# 4) 构建产物复查
npm run build
grep -rnE "大学|学院|参赛|科技进步" dist || echo "产物无身份关键词"

# 5) 提交身份复查
git log --format='%an <%ae> | %s'
```

## 三、部署阶段的强制要求（清单）

- [ ] 仓库名中性（如 `antigen-interactive-course`），描述与 topic 不含单位、姓名、比赛；
- [ ] 提交身份中性：`git config user.name "course-maintainer"`、`git config user.email "maintainer@users.noreply.github.com"`；
- [ ] 不使用带个人姓名/头像的 GitHub 账号作为公开贡献者（如不可避免，改用组织账号或迁移仓库）；
- [ ] 不启用第三方评论、统计、字体等会暴露来源的外部脚本；
- [ ] GitHub Pages 地址为 `<账号>.github.io/<仓库>/` 时，检查账号名本身是否可识别身份；
- [ ] 二维码生成后目视复核：指向地址正确、无跳转、无第三方短链；
- [ ] 若需自定义域名，使用中性域名，并确认续费与 DNS 维护责任。

## 四、结论

当前仓库内容通过上述检查：页面文字、元信息、注释、资源、链接与图示均不含可识别身份的信息；站点不含位图与视频，从源头消除了水印、EXIF 与版权不明风险；涉及奖项/归属的表述已改为技术路径描述并附匿名化说明。

**遗留风险仅存在于部署环节**（账号名、仓库名、提交身份、域名），需按第三节清单逐项确认后再公开部署。
