# 架构验证记录：真的能“换一章只改内容”吗？

> 这份记录是为了检验一条我此前只是**声称**过的架构承诺：
> 「以后只需更换每一章节的 PPT、知识点、图片、视频和互动内容，即可开发后续 7 个课件」。
>
> 验证方法：用 workspace 里现成的第 2 个课件《免疫器官·骨髓》（21 页真实课堂课件），
> 按 README 的说明新建 `src/content/bone-marrow/` 四个数据文件，**只在注册表里加一处**，
> 然后把 `activeCourse` 指向它，看页面是否真的呈现出第 2 章的内容。

### 缺陷根因

1. **`getModule()` / `getQuestion()` / `questionsOf()` 写死了 `antigenBundle`**
   → 换了 `activeCourse`，模块详情仍读第 1 章的数据（`src/content/index.ts`）。
2. **`Classroom.tsx` 直接索引写死的题号** `activeCourse.questions['cl-t2']` 等 3 处
   → 新章节没有这些 id 时取到 `undefined`，传给 `QuestionCard` 后崩溃。
3. **作业页 `answered / allIds.length` 在空数据时除零**，且渲染空列表无兜底。

## 三、仍然存在的缺口（开发第 2—8 章前必须知道）

以下问题**不影响第 1 章的交付**，但会让新章节出现“内容换了、标题没换”的错位：

1. **页面标题与导语仍写死在页面里**，没有进入内容层。例如：
   - `/modules`：「按课件三条主线，逐层深入」
   - `/cases`：「三个问题，三种'用得上'的免疫学」
   - `/frontier`：「从'表位'到'设计'」
   - `/ideology`：「四个融入点：从分子机制到职业责任」
   - `/classroom`：「六个任务，把'看懂'变成'会做'」
   → 建议下一步把这些文案移入 `CourseConfig`（新增 `pageCopy` 字段）。

2. **课堂互动 6 个任务的“情境/机制/小结”文本仍写在 `Classroom.tsx` 里**
   → 第 2 章的任务类型不同（例如“造血谱系排序”“HIM/HSC/MSC 归类”），
     需要把任务定义数据化为 `course.classroomTasks`。

3. **`REQUIRED_PAGES` 是全局常量**，多课程共存时要按课程区分。

4. **`localStorage` 的 key 是固定的** `vei.antigen.progress.v1`
   → 多课程同域名部署时会共用一份进度，需加课程前缀。

## 四、这次的处置

验证用的第 2 章内容（`src/content/bone-marrow/`）已**移除，不随本次交付公开**：
按任务要求「不要现在生成 7 个空壳网站，也不要把它们作为已经完成的模块展示」，
第 2 章仅有 2 道题、1 个案例，属于验证样本而非成品，不应出现在站点导航里。

架构修复保留，因为它同时提升了第 1 章的健壮性

## 五、给后续开发的建议顺序

```
1. 先把 pageCopy 与 classroomTasks 数据化（约 1 次重构，两处组件改动）
2. 再把 localStorage key 加课程前缀、REQUIRED_PAGES 移入课程包
3. 之后才是按章写内容——此时才真正做到“只改内容”
```
