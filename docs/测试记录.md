## 三、站内链接巡检（`node scripts/check-links.mjs`）

结果：**扫描 13 个页面，39 条唯一链接、13 条站内路由、23 条页内锚点，全部有效；外部链接 1 条**。

- 外部链接仅为 `https://www.ncbi.nlm.nih.gov/books/NBK10759/`（公开教材术语表），无第三方统计/字体/短链；
- 页内锚点验证方式：直接以 `#/路径#锚点` 打开，检查目标元素存在。

> 巡检中发现并修复的真实缺陷：
> ① HashRouter 下 `href="#id"` 会破坏路由（页面跳成 404）→ 改为 `ScrollLink` 组件（滚动 + 聚焦，不改路由）；
> ② 3D canvas 绝对定位覆盖工具栏，导致“暂停旋转/复位/部件显隐”按钮点击被拦截 → 改为视口/工具栏分离布局。

## 四、三维渲染的像素级核验

为避免“看起来有 canvas 但其实没画东西”，对截图做了量化分析：

| 模型 | 亮部像素占比 | 结构包围盒占视口 | 部件开关对画面的影响（像素差异） |
|---|---|---|---|
| 抗体—抗原（首页） | 7.4% | 80% × 96%（未触边） | 变性开关切换后构象表位消失、画面变化可检测 |
| 细菌（结构解剖台） | 10.7% | 主体居中，中心区 71.7% | 荚膜 5636、鞭毛 1885、磷壁酸 1120、菌毛 768 像素差异 |
| 病毒（结构解剖台） | 通过 | 主体居中 | 包膜/衣壳/核酸/糖蛋白四个开关均生效 |

同时修正了取景问题：新增“包围球自适应取景”（`fit.radius`），按视口宽高比自动计算相机距离；抗体模型整体居中，避免窄屏裁切。

## 七、如何复跑

```bash
npm install
npm run typecheck
npm run build
npm run preview:test          # 终端 A：启动 4321 端口预览
npm run e2e                   # 终端 B：自动化验收（Edge）
node scripts/check-links.mjs  # 终端 B：站内链接巡检
```

若本机只有 Chrome：`E2E_CHANNEL=chrome npm run e2e`。
